# Teams languages for voicemail greetings and messages - Microsoft Teams | Microsoft Learn

When you set up voicemail in Microsoft Teams, you can choose the language for the default system messages and voicemail greetings.

Teams supports the following languages for voicemail greetings and messages. The table lists the languages available for voicemail greetings and messages, the country or region where the language is used, and whether the language is available for users to see in email, when they call in, and if transcription is available.

Voicemail transcription language support is based on the capabilities provided by the [Azure Speech Fast Transcription multilingual model](/en-us/azure/ai-services/speech-service/llm-speech). As new languages become available in the Azure Speech service, they will become available for voicemail transcription as well. For the most current list of supported transcription languages, see [multilingual model supported languages](/en-us/azure/ai-services/speech-service/llm-speech). Because language support evolves over time, the information in this article may not always reflect the latest available languages.

To use voicemail transcription, ensure that transcription is enabled in your organization's [Voicemail policies](manage-voicemail-policies). Enabling transcription not only allows users to read voicemail messages but also enables advanced AI-powered voicemail experiences.
