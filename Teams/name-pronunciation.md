# User name pronunciation in Teams - Microsoft Teams | Microsoft Learn

Name pronunciation is part of a user's profile in Microsoft Teams (and throughout Microsoft 365). Users can help their colleagues learn how to pronounce their name by adding a recording of their name to their Microsoft 365 profile card.

This setting is turned off by default. If you would like to turn on name pronunciation for your users using the Teams admin center, follow the steps in this article.

If you need to manage name pronunciation settings for your users, see [Manage pronunciation settings for an organization](/en-us/graph/namepronunciation-configure-namepronunciation-availability).

## Turn on name pronunciation for your users

Turn on name pronunciation for your users by completing the following steps:

1. Sign in to the [Microsoft 365 admin center](https://go.microsoft.com/fwlink/p/?linkid=2024339) with your admin credentials.
2. In the left-rail navigation, expand **Settings** and select **Org settings**.
3. On the **Org settings** page, select the **Security & privacy** tab.
4. In the list of settings, select **Name pronunciation**.
5. On the **Name pronunciation** pane, check the **Turn on and allow name pronunciation** checkbox.
6. Select the **Save** button.

Your users can now record themselves stating their name and listen to other users' name pronunciations.

## User experience of name pronunciation

In a user's [profile card](https://support.microsoft.com/office/profile-cards-in-microsoft-365-e80f931f-5fc4-4a59-ba6e-c1e35a85b501), they see a microphone icon. Pressing the microphone icon pops up a box where they can record themselves stating their name. They can listen to the recording and choose to re-record or save the recording.

When other users pull up that user's profile card, they can press the microphone icon to hear their name pronounced.

A user can choose to opt in or out of name pronunciation. For more detailed instructions on how users can display a name pronunciation, see [Record and display your name pronunciation on your profile card](https://support.microsoft.com/office/record-and-display-your-name-pronunciation-on-your-profile-card-8553d377-d0ca-40d4-8281-425dabcf55e2).
