# Emergency calling disclaimer labels - Microsoft Teams | Microsoft Learn

These labels are emergency calling (911) disclaimer labels or stickers for use with Avery 5160 address labels (1" x 2 5/8"). They can be sized if you want to use other types of labels.

[Select to download a .zip file for Emergency Calling labels (en-us)](https://download.microsoft.com/download/9/9/0/990e24c1-eb49-4b52-9306-dbd4c864ed91/emergency-calling-label-%28en-us%29-%28v.1.0%29.zip).
