# Introduction to Moodle LMS - Microsoft Teams | Microsoft Learn

Moodle is one of the largest open-source learning management systems (LMS). It provides a unique remote learning experience powered by secure privacy services. Moodle LMS integrates with Microsoft Teams to provide the following services:

- Audio or video calls
- Chat with students
- Courses and activities
- Badges and rewards
- Analytical insights

## Moodle LMS accessibility

Moodle LMS helps users access the following apps:

- **Microsoft 365 plugins**: The Microsoft 365 plugins ensure integration between Moodle sites and Teams. Use these plugins independently or in partnership to achieve distinct user requirements. For more information, see [Microsoft 365 plugins](m365-plugins-overview).
- **Partner apps for Moodle**: Find partner apps for Moodle and Teams in the Microsoft Store. For more information, see Partner apps for Moodle.

## User requirement scenarios

The following scenarios describe the accelerated learning potential when you combine Microsoft's cloud services with Moodle's courses:

- **Facilitate hybrid remote meetings**: Use Teams meetings and extensibility services to present in-person and remotely with students. Students must access shared views, apps, and polls for remote meetings. Use the follow-up tasks for multi-language transcription and audio or video course recordings. Teams and Moodle work together to share rosters, activities, and tasks.
- **Personalize meeting panels**: Create unique collaborative learning experiences by using Teams Graph API endpoints. For other plans or projects, interview all new recruits and categorize the results by using custom polls. Share quizzes directly in Teams while pushing updates to the Moodle site asynchronously.
- **Automate facility**: Set up automated facilities for institutions when a new student joins. Add a Moodle course, send an Adaptive Card to the student with relevant links, and suggest key reading course materials. Use Teams custom connector for Moodle to create a Moodle calendar event each time a course meeting is scheduled.
- **Build citizen developer apps**: Develop new custom apps for your school that are easy to create and help optimize learning. The app also provides easy-to-use transactional activities for students and faculty.

## Partner apps for Moodle

The Microsoft Store provides all the certified partner apps for Moodle, which validate Software as a Service (SaaS) offerings. mConnect, a partner app for Microsoft, integrates Moodle courses with Teams.

### Key benefits of partner apps for Moodle

The following table shows the advantages of using partner apps:

| Advantages | Description |
| --- | --- |
| Extend Teams to fit your needs | Install and engage with apps designed by experts for improved student engagement and collaboration. |
| Enable single sign-on (SSO) | Enable SSO for users of Teams and Moodle to access Moodle courses, data, and activities within Teams. |

## mConnect

The mConnect app integrates Moodle courses and activities into Teams to enhance users' learning experience. Skooler, a trusted Microsoft Gold partner in education, developed the mConnect app and provides the necessary support.

mConnect allows Moodle administrators to set up Teams for Moodle courses automatically and to make all features available for each course in Moodle.

Note

The mConnect app is available in Microsoft Store for users who have a pre-existing account with Skooler and requires administrator access rights to configure it directly from the Moodle site.
