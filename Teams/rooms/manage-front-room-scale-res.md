# Remotely configure layout, scale, and resolution on Teams Rooms displays - Microsoft Teams | Microsoft Learn

Important

Starting from Teams Rooms on Windows version 5.6.130, we recommend to configure display layout, resolution, and scaling using the Teams Rooms Pro Management Portal.

If you have multiple Teams Rooms systems deployed in your organizations, you can configure display settings such as scale, resolution, and default layout, remotely using the Pro Management Portal settings. For the latest guidance on available settings and configuration options, see [Managing Teams Rooms on Windows settings](/en-us/microsoftteams/rooms/pro-portal-settings).

You can use the Pro Management Portal to:

- Configure front-of-room display resolution and scaling
- Set default meeting layout; room users can still change the layout during a meeting.
