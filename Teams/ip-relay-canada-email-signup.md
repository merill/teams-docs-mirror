# IP Relay in Canada - sign up - Microsoft Teams | Microsoft Learn

Internet Protocol Relay Service, also known as IP Relay, is a service that supports people with hearing or speech disabilities, using an operator as an intermediary.

To get an IP Relay account set up for Canada, open a case with the [Telephone Number Services service desk](manage-phone-numbers-for-your-organization/contact-tns-service-desk), and provide the following information.

- First and last name:
- Microsoft 365 or Office 365 organization domain name: (Example: Contoso.com)
- Microsoft 365 or Office 365 user phone number: (Example: +1 XXX XXX XXXX)
- Password (8 to 16 characters):
- Most likely physical address at the time of an emergency:
- Street number and name:
- Apartment / Suite:
- City:
- Province / State:
- Postal code / Zip code:
- Phone number:
- Microsoft 365 or Office 365 email address:

    Note

    The email address you provide receives messages left for you if you're not online when someone calls for you via IP Relay.

When your account is ready (within 24 working hours), you're provided with the user name and password.

Next, see [IP Relay in Canada - user guide](ip-relay-canada-user-guide) to get started.
